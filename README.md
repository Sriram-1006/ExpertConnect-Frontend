# ExpertConnect Frontend

React 18 application built with Vite.

## Requirements

- Node.js and npm
- ExpertConnect backend running at `http://localhost:8080`, unless configured otherwise

## Run locally

```powershell
npm install
npm run dev
```

Vite serves the app at `http://localhost:5173`. Set `VITE_API_BASE_URL` in a local `.env` file to change the API URL. See `.env.example` for the template.

## Production build

```powershell
npm run build
npm run preview
```
